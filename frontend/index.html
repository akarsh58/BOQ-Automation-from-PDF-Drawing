BOQ Automation

Bill of Quantities generator from PDF/IFC drawings using IS 1200 and CPWD rates.

Workflow:

  1. Upload a PDF or IFC model via the API endpoint POST /preview
  2. Review detected rooms and walls, adjust scale calibration (/generate requires calibrated scales)
  3. Generate the tender BOQ Excel workbook (POST /generate or POST /generate-boq)
  4. Record QA reviews (POST /qa-review) and validate requirements (POST /qa-validate)

Knowledge base: CPWD-style rates from knowledge_base/cpwd_rates.csv (82 items, 13 categories).

Measurement standard: IS 1200 (Indian Standard).

For a complete API server, run: uvicorn app.main:app --reload
